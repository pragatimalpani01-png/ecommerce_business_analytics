# Resume bullets you can adapt

Use these after you have run the project and can explain the choices behind the metrics. Do not quote the demo figures as business results.

- Built a Python analytics workflow that joins order, item, payment, product, seller, customer and review data into order-level and item-level reporting tables.
- Defined delivery promise-gap, on-time delivery, customer repeat-order and service-friction measures, with documented assumptions and data-quality checks.
- Developed a standalone Plotly dashboard and a set of static charts for monthly sales activity, delivery performance, category screening, seller exceptions and customer cohorts.
- Wrote SQL queries for monthly performance and category and seller review queues, and packaged the analysis tables in SQLite for reuse.
- Created a service-recovery budget planner that estimates contact workload and cost without treating associated item value as guaranteed lost or recoverable revenue.

Once you run the analysis against the original data, add one result you can defend in an interview. Include the period, the definition of the measure, and the business implication. Leave out any number that came only from the synthetic demo.
