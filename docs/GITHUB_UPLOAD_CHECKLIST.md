# Before publishing to GitHub

1. Extract the ZIP and keep the folder structure intact.
2. Read the note at the top of `README.md`. The bundled CSVs are synthetic demo data.
3. Run `python run_project.py --source demo` locally and check the dashboard and PDF report.
4. If you download the original Olist dataset, keep the raw CSV files out of the public repository unless you have checked the license. The project's `.gitignore` excludes them by default.
5. Upload the project files, including the README and static chart images. GitHub will show the chart previews inside the README.
6. After you run the original data, review the new report and remove any statement you cannot support with the actual outputs.
