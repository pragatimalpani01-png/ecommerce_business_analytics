# Data folders

- `demo/` contains synthetic CSV tables so the project can run immediately. They are not original Olist records.
- `raw/` is where the original Olist CSV files go after you download them. Raw files are ignored by Git by default.

The source files are available from the [Olist Brazilian E-Commerce Public Dataset](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce). A free Kaggle account is required, and the published dataset uses the CC BY-NC-SA 4.0 license. See `DATA_LICENSE.md` before sharing adapted data.
