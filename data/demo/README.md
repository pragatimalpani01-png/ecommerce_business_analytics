# Demo tables

These CSV files contain synthetic records created by `scripts/make_demo_data.py`. They use the main column names found in the public Olist tables so the analysis can run straight after downloading the repository.

They are not copied from Olist, and the numbers generated from them are not findings about Olist or a real retailer. To use the original transactions, download the CSV files from the Kaggle source, put them in `data/raw/`, and run `python run_project.py --source raw`.
