# Charts

The charts in this folder are regenerated by `scripts/analyze.py`.

- `monthly_performance.png` compares monthly order count with delivered item value.
- `category_opportunity_map.png` compares delivered item value with low-review share; color shows the late item-line share. Order-level reviews are carried onto item lines, so this is a screening view rather than product-specific feedback.
- `promise_gap_distribution.png` shows actual delivery date minus estimated delivery date. Positive values mean late delivery.
- `delivery_review_relationship.png` compares average review scores across delivery-promise groups.
- `seller_service_friction.png` shows sellers with the highest screening score among sellers with enough delivered orders.
- `customer_cohort_activity.png` shows the share of each first-order cohort that placed another order in a later month.

The included PNGs use synthetic demo data. The footer in each chart labels them as demo data. Rerun the project with the original Olist files to replace them with source-data results.
